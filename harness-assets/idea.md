# demou

由 analysis 從 README 整理（2026-10-27），不是使用者的原話。

## 要做什麼

家族的操作教學 app：動手按，學會 terminu 家族的操作。家族每一個 app 的操作都一樣：同一組鍵用來移動、找出能做的事、關掉打開
的東西。demou 是拿來練這些鍵的書架，一個畫面練一部分：看與移動、找動作、popup 疊 popup。學會的在家族每個 app 都能用。

## 給誰用

- 家族的影片：錄家族共用操作的那一段。
- 看了影片的人：裝起來跟著按。

## 在哪些平台

macOS 與 Linux（WSL 也可以），沒有 Windows 版。終端機要有 Nerd Font、truecolor，至少 60 欄寬、24 列高。

## 哪些事不能發生

- 不存任何東西：書是練習用的假資料，只在 demou 開著時存在；加的、搬的、拿掉的書，離開就不見了。每次啟動都是同一個放著
  二十本經典的書架。
- 不碰使用者的任何檔案。
